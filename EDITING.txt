세온 시설관리 — 수정 안내

index.html을 브라우저에서 열면 별도 설치 없이 실행됩니다.

파일 구성
index.html: 화면 구성과 회사 소개
style.css: 색상, 레이아웃, 모바일 대응
content.js: 이미지 비율/맞춤 및 모든 작업 기록
images.js: 외부 이미지 URL
app.js: 이미지 자동 맞춤, 검색/분류, 문서 열기


이미지 교체
images.js의 각 빈 따옴표에 외부 이미지 직접 HTTPS URL을 입력합니다.
예: hero:'https://your-domain.com/facility.gif'
비율과 맞춤 설정은 content.js의 SEON_IMAGES에서 변경합니다.
ratio 값: landscape(1216×832), portrait(832×1216), square(1024×1024), auto(원본 비율)
fit 값: contain(이미지 전체 표시), cover(잘라서 빈틈없이 채움)
미등록 또는 불러오지 못한 이미지는 회색으로 표시됩니다.

문서 수정
SEON_RECORDS 배열의 id, type, date, title, body를 편집합니다.
body는 [소제목, 본문]의 배열입니다. 문서를 추가하면 목록에 자동 반영됩니다.
분류는 '현장 기록' 또는 '관리 안내'로 지정합니다.

설정 메모
모든 기록과 날짜는 임시 창작 설정입니다.
회복 대기실/격리실 명칭 불일치, 훈련 시나리오 입력, IN-001 출입 해제,
G-series 피복 회수 지침을 다른 사이트의 문서와 대조하는 구조입니다.
실제 인증 시스템이나 비밀문서 보안 기능은 없습니다.
연락처는 미정이며 문의 전송 기능은 포함되어 있지 않습니다.

GIF / animated WebP / PNG / JPG 지원. GIF는 움직임을 유지합니다.
공유 페이지 주소가 아닌 이미지 파일 주소를 사용하세요. 외부 표시를 허용하는 이미지 호스트가 필요합니다.
기본 contain 자동 맞춤과 기존 이미지 비율, 기믹은 유지했습니다.
